# Directory Fuzzer — Gobuster Tools Version

Professional web content discovery walkthrough using Gobuster against an Apache web server.

## Contents

| File | Description |
|------|-------------|
| `gobuster_guide.md` | Step-by-step walkthrough — directory scan, file discovery, response code analysis |
| `screenshots/` | Screenshots from each Gobuster run and HTML report |

## Workflow

1. Set up hidden directories and files on the target
2. Run Gobuster to discover hidden directories
3. Fuzz inside discovered directories to find sensitive files
4. Analyse findings and document defensive recommendations

See `gobuster_guide.md` for the full walkthrough.
