# Project 4: Directory Fuzzer

A web content discovery tool that finds hidden directories and sensitive files on web servers — built from scratch in Python and demonstrated professionally with Gobuster.

## Versions

### Python (`python/`)
A multi-threaded directory fuzzer with file extension discovery and professional HTML report generation. Finds hidden paths, exposed backup files, and misconfigured directories.

### Gobuster (`tools/`)
A professional walkthrough of web content discovery using Gobuster — directory enumeration, file extension fuzzing, and defensive recommendations.

## Skills Demonstrated

- HTTP request handling and response code analysis
- Multi-threaded fuzzing
- File extension discovery (`.php`, `.bak`, `.txt`)
- HTML report generation with colour-coded findings
- Gobuster directory and file enumeration
- Web server hardening recommendations

> **Note:** Only use against web servers you own or have explicit written permission to test.
