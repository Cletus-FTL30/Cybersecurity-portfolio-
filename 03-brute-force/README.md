# Project 3: Brute Force Tool

A brute force tool for SSH and FTP services — built from scratch in Python and demonstrated professionally with Hydra.

## Versions

### Python (`python/`)
A multi-threaded brute force tool built with Paramiko and ftplib. Supports SSH and FTP, configurable threads, and log file output.

### Hydra (`tools/`)
A professional walkthrough of brute force attacks using Hydra — wordlist preparation, SSH and FTP attacks, and defensive countermeasures.

## Skills Demonstrated

- SSH and FTP authentication with Paramiko and ftplib
- Multi-threaded attack implementation
- Wordlist-based password attacks
- Hydra usage for SSH and FTP brute forcing
- Defensive recommendations (fail2ban, SSH keys, MaxAuthTries)
